# Интернет — территория безопасности

Статический образовательный проект о цифровой грамотности. Главная страница — компактное меню без прокрутки; каждая тема и мини-тест открываются отдельным HTML-файлом.

## Публикация на GitHub Pages

1. Загрузите содержимое проекта в корень репозитория: index.html, quiz.html, questions.json, topics/, assets/, CSS и JS.
2. В настройках репозитория откройте Pages и выберите публикацию из нужной ветки и папки корня (/(root)).
3. Откройте выданный GitHub Pages URL. Ресурсы загружаются по относительным адресам, поэтому работают и для сайта репозитория (например, https://username.github.io/repository/), и для пользовательского домена.

GitHub Pages раздаёт сайт через HTTPS, отдельный локальный сервер для публикации не нужен. Открытие index.html непосредственно через file:// не поддерживает загрузку JSON через fetch. Тест предназначен для GitHub Pages или другого статического HTTP-хостинга.

## Структура

- index.html — главная навигация, рассчитанная на один экран.
- topics/*.html — самостоятельные страницы тем.
- quiz.html — отдельная страница мини-теста.
- questions.json — 100 вопросов в 10 темах; в каждом тесте случайно выбираются 10 без повторов.
- style.css и script.js — оформление и логика теста.
- assets/images/*.svg — локальные заменяемые иллюстрации.

Для локальной проверки можно запустить любой статический сервер из корня проекта, например python -m http.server 8000 и открыть http://localhost:8000. Это необязательно для GitHub Pages.
